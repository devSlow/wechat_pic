一个面向日常图片处理场景的微信小程序，主打证件照制作、图片拼接、图片压缩、格式转换、文字水印和验证码查询等常用能力。

## 项目介绍

咔拼鸭是一款偏轻量、偏高频场景的图片工具类微信小程序，目标是让用户在手机端快速完成图片处理，不依赖复杂软件，也不需要繁琐步骤。

整个小程序围绕“选择图片 - 处理图片 - 预览结果 - 保存导出”来设计，重点覆盖以下几类实际使用场景：

1. 证件照制作
2. 图片拼接与宫格处理
3. 图片压缩与格式转换
4. 图片加水印
5. 扫码辅助验证码查询

相比偏专业的桌面工具，这个项目更强调：

1. 操作简单
2. 手机上可直接完成
3. 常见需求一站式处理

## 主要功能

### 证件照制作

支持从拍照或相册导入照片，自动生成对应规格的证件照。

功能包括：

1. 常用规格快速选择
2. 按通用、考试、签证分类查看更多规格
3. 自动处理并生成证件照
4. 支持切换背景颜色
5. 支持高清画质开关
6. 支持单张预览与 6 寸排版预览切换
7. 支持保存到相册

### 图片拼接

支持将多张图片合并成一张图片，适合做长图或横向拼接图。

功能包括：

1. 多图拼接
2. 竖向拼接
3. 横向拼接
4. 生成后直接保存

### 宫格拼图

支持把多张图片按照固定布局排成一张拼图。

支持布局包括：

1. 二宫格
2. 三宫格
3. 四宫格
4. 六宫格
5. 九宫格

适合社交平台发图、内容整理和简单展示场景。

### 九宫格切图

支持将一张图片切成九宫格切片，适合朋友圈或社交平台分图发布。

功能包括：

1. 单图切九宫格
2. 切片预览
3. 一键保存全部切片

### 图片压缩

支持批量压缩图片大小，方便报名上传、表单提交和分享前减小体积。

功能包括：

1. 最多 9 张批量压缩
2. 滑块调整目标大小
3. 常用压缩档位快捷选择
4. 展示原始大小、压缩后大小和压缩率
5. 批量保存压缩结果

### 文字水印

支持为图片添加自定义文字水印。

功能包括：

1. 输入水印文字
2. 选择文字颜色
3. 调整透明度
4. 调整角度
5. 调整字号
6. 保存带水印图片

### 图片格式转换

支持在不同图片格式之间进行转换。

当前支持：

1. PNG
2. JPG
3. WebP
4. BMP
5. TIFF

适合上传格式不兼容、透明图转换、压缩率优化等场景。

### 验证码查询

小程序内提供验证码查询页，可配合网页端验证流程使用。

功能包括：

1. 扫码自动读取 SessionID
2. 自动查询验证码
3. 手动输入 SessionID 查询
4. 直接展示验证码结果

## 页面说明

当前小程序主要包含以下页面：

1. `pages/index/index`
证件照制作主页

2. `pages/stitch/stitch`
图片拼接、宫格拼图、九宫格切图

3. `pages/tools/tools`
图片压缩、文字水印、格式转换

4. `pages/verify/verify`
验证码查询

5. `pages/mine/mine`
关于、协议、隐私等入口
